# This is a fan-made game based on Touhou Project by Team Shanghai Alice. All rights goes to them
Player have money and experience. Money can be spent on upgrades while experience for now does nothing. </br>
Defeated mobs give you money and exp depending on location/mob level/upgrades. </br>
Server can be connected to store player data and detect cheating
